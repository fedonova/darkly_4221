# Bruteforce

Пробуем забрутфорсить форму логина `http://IP/?page=signin`. Для этого пишем скрипт, который читает два файла с самыми популярными паролями и логинами, перебирает их и делает запрос на адрес:

```text
http://${ip}/?page=signin&username=${login}&password=${password}&Login=Login#
```

По этому запросу возвращается текст страницы. Если пара неверна, на странице есть картинка под названием `WrongAnswer.gif`. Если такая картинка отсутствует — записываем пару в файл и пробуем залогиниться. Так и получаем флаг.

## Как защититься от bruteforce?

1. Устанавливать правила блокировки учётной записи после определённого количества неудачных попыток входа, чтобы предотвратить подбор учётных данных.  
2. Внедрять CAPTCHA (ввести текст с картинки, кликнуть по картинкам, решить простую задачу и т.п.), если блокировка невозможна. CAPTCHA, которую я так ненавижу, делает bruteforce медленным, сложным и очень ресурсозатратным.  
3. Заставлять пользователей менять пароль при первом входе в систему, если используется пароль по умолчанию. Этот сценарий нужен, когда учётка создаётся за тебя, например, на корпоративных платформах. В таком случае у тебя изначально есть только дефолтный пароль, который ты должен поменять при первом же логине. Ещё один пример — дефолтные пароли на оборудовании, вроде `admin:admin` на роутере.  
4. Использовать многофакторную аутентификацию, когда пользователю нужно подтвердить вход с дополнительного устройства.

Польза для злоумышленника здесь — получить доступ к аккаунту пользователя.
