OWASP Top 10 — это список категорий рисков. У каждой категории есть свой номер, например A05:2025, где:
A — Application risks;
05 — пятая в списке;
2025 — год версии.

В каждой категории есть классификация уязвимостей, которые обозначаются как CWE-79, где:
CWE — Common Weakness Enumeration;
79 — номер в перечне.
